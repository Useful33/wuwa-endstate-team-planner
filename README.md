# 鸣潮终焉矩阵配队工具

Windows 桌面配队工具，当前版本 **v2.0**。左侧管理队伍，右侧管理已持有角色；默认提供 8 支队伍的位置。

## 直接运行

下载本仓库的 [Windows 可执行文件](dist/鸣潮终焉矩阵配队工具-v2.0.exe)，双击运行。适用 Windows 10/11，需要系统 .NET Framework 4.8；不需要安装 Python、Node.js，也不需要另外下载图片素材。

## 功能

- **粘贴截图识别**：复制游戏内角色列表截图，在工具里按 Ctrl+V。支持多张截图、角色区域框选、3×4 / 4×3 等排列、结果核对及去重合并。
- **漂泊者同步**：从头像识别性别、从属性图标识别属性。确认合并后覆盖手动设置，更新持有形态、队伍和头像。
- **出场次数管理**：普通角色默认 1 次；白芷、维里奈、卜灵、守岸人、莫宁、穗穗、莉莉各 2 次。同队不能重复。
- **额外二次名额**：再指定一名原本限用一次的角色使用两次，手动配队、校验和推荐同步生效。
- **一键推荐**：使用已持有角色和攻略站收录组合，优先覆盖限定五星，并按主力首次推出时间从早到晚排列。主力放在第一格。
- **攻略溯源**：推荐队伍可查看攻略作者、更新时间和原文链接。内置 168 篇中文攻略的 869 个首选/备选组合。
- **编辑与备份**：角色等级、共鸣链、备注，队伍命名，自动保存，Ctrl+Z 撤销，JSON 迁移，PNG 导出、文本复制。
- **一键清空**：分别支持清空全部配队或全部截图及待识别队列。

推荐默认保留手动配队，只填完全空白的队伍。右键“一键推荐”可重新规划全部；角色或攻略搭配不足时会留空。推荐不是实际伤害计算，也不保证特定关卡分数。

截图识别在本地完成，不上传图片。低置信度结果需要手动核对；漂泊者设置以最后加入且勾选的识别结果为准。

莉莉是本地自定义角色，官方资料为衍射 / 佩枪 / 5 星（来自 encore.moe），使用官方头像并默认可出场 2 次；官方头像模板已嵌入，可用于截图识别，低置信度结果仍请手动核对。

详细说明见 [使用说明](docs/使用说明.txt)。素材与攻略来源见 [资料来源](docs/SOURCES.md)。

## 从源码构建

在 Windows PowerShell 中，于仓库根目录执行：

```powershell
powershell -NoProfile -File .\source\build.ps1
```

脚本调用 Windows .NET Framework 的 C# 编译器，将 `assets` 内的数据、角色头像和属性图标嵌入单个 exe。生成文件位于仓库根目录：`鸣潮终焉矩阵配队工具.exe`。

## 检查

```powershell
powershell -NoProfile -File .\test.ps1
```

当前内置检查为 **496 项**，涵盖角色配额、推荐分配、数据兼容、漂泊者设置覆盖、额外二次名额、剪贴板位图格式和素材解码。原始截图及私人存档不包含在本仓库中；需要真实截图输入的人工/图像检查不属于上述离线自检命令。

## 目录

```text
source/          C# / WPF 源码及构建脚本
assets/          内置角色数据、头像、属性图标和攻略组合
dist/            已构建的 v2.0 可执行文件
docs/            使用说明与资料来源
tests/results/   自检结果
test.ps1         一键运行内置自检
```

本地存档由程序保存在 `%LOCALAPPDATA%\WuwaEndstateMatrix\`。仓库不包含玩家截图、剪贴板内容、持有角色记录、个人账号资料、旧版本备份或登录凭据。

本项目是玩家制作的非官方工具。攻略来自《鸣潮》官方攻略站收录的玩家作者内容；站点归属不代表这些配队是官方强度排名。内置攻略与角色资料的核对日期为 2026-11-09，推荐本身可离线使用，原文链接需要联网。
