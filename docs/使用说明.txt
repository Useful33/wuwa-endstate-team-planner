鸣潮 · 终焉矩阵配队工具 2.0

运行
双击“鸣潮终焉矩阵配队工具.exe”。单个 exe 已包含所有角色头像和角色资料，运行时不需要联网、Python、Node.js 或额外素材文件。
适用 Windows 10 / 11，使用 Windows 的 .NET Framework 4.8 和 WPF。

开始配队
1. 首次打开进入“管理持有”，点击角色卡片勾选你拥有的角色。支持全选、全不选。
2. 点击“完成管理”。右侧仅显示持有角色。
3. 点击左侧队伍中的一个位置，再点击右侧角色，将角色加入或替换到该位置。
4. 加入角色后自动选中同队的下一个空位。
5. 点击角色位置右上角的 × 移除角色；也可右键该位置移除。已消耗的次数立即返还。
6. 队伍标题可直接修改；支持新增、清空和删除队伍。左侧队伍列表和右侧角色池分别滚动。
7. 点击左侧“作战编队”顶部的“清空全部”，一键移除所有队伍中的角色并返还全部出场次数；保留队伍数量、名称、角色持有和角色资料。清空后自动保存，按 Ctrl+Z 可一次恢复全部配队。所有队伍为空时按钮会置灰。

出场次数
普通角色默认全局最多使用 1 次；可在左下“特殊角色”中额外指定一名角色使用 2 次。
白芷、维里奈、卜灵、守岸人、莫宁、穗穗：每人全局最多使用 2 次。
同一个队伍中不能重复放入同一角色。
漂泊者由专门的“漂泊者设置”统一选择性别与当前属性，角色池只显示所选的一种形态，默认总共使用 1 次，设为特殊角色后可使用 2 次。
卡片右上角显示“剩余次数 / 总次数”；不满足当前位置条件的角色变暗，点击会说明原因。
“仅看可用”按当前选中位置筛选，替换原位置的同一角色仍然合法。

漂泊者设置
点击右侧角色区顶部“漂泊者：男/女 · 属性 ⚙”，打开设置窗口。
性别可选择男或女；属性可选择内置名单中的衍射、湮灭、气动、导电。
窗口会实时预览对应性别的头像，点击“保存设置”后生效，点击“取消”不修改。
角色池（包括管理持有和全选）只保留所选属性的一个漂泊者，不会将多种属性作为多个角色列出。
切换性别同步更新角色池、已编队角色和导出图片中的漂泊者头像。
切换属性会自动替换队伍中的漂泊者，保留队伍位置和持有状态，已使用的次数不会重置。
新属性尚未填写资料时，继承旧属性的等级、共鸣链和备注；已有该属性资料时保留其资料。
性别与属性设置会自动保存，并随 JSON 方案一同导入导出；支持 Ctrl+Z 撤销设置变更。
旧版方案自动迁移：优先采用已编队漂泊者的属性，否则采用首个已持有属性；没有漂泊者时默认男·衍射。旧头像性别也会按原条目保留。

粘贴截图自动识别（v1.4）
1. 在游戏中截图，或在聊天/图片软件中复制截图，确保剪贴板中是图片。
2. 切换到本工具，按 Ctrl+V；也可点击主界面顶部“粘贴截图识别”。截图会直接进入识别窗口并自动开始识别。
3. 识别窗口内也支持 Ctrl+V 或“粘贴截图”按钮。可以连续粘贴多张；上一张尚未完成时，新截图会排队自动识别，所有结果汇总显示。
4. 图片在内存中处理，不需要玩家保存或选择本地图片文件。剪贴板为空或只有文本时会提示；搜索框等文本输入中的正常文字粘贴仍然可用。
5. 默认根据截图方向采用 3 列 × 4 行或 4 列 × 3 行。若包含游戏菜单等无关区域，可拖动框选角色列表，调整列/行后点击“识别本张”重识别。最多识别 48 个位置。
6. 右侧可核对截图头像、首选角色和相似度，并用下拉框手动更正。较低相似度的结果默认不勾选；核对后勾选或点击“勾选全部结果”。相似度是图像指标，不是正确概率。
7. 点击“合并到已持有”，仅加入勾选且尚未持有的角色；重复角色自动去重。原有队伍、等级与共鸣链保持不变。
8. 导入自动保存，Ctrl+Z 可一次撤销整次合并。“打开图片”保留为可选入口。
9. 识别窗口右上角“清空所有截图”可一键清除全部截图、识别结果、预览和等待队列。正在识别时也能清空，旧任务会取消，旧结果不会再次填回。清空后可以继续粘贴；已持有角色与已有配队不受影响。

识别完全在本地执行，使用 exe 内置头像模板，不上传截图，不需要 API Key 或联网。
漂泊者通过头像识别性别、通过左上角属性图标识别属性。核对并合并后，截图结果会覆盖此前的手动性别/属性选择，并同步替换已编队的漂泊者；没有新增持有角色时也会更新。属性图标不清晰的结果会提示核对。多图冲突按截图加入顺序，采用最后一张已勾选的漂泊者结果。
适用于游戏角色列表中与内置头像一致的头像卡片。遮挡、模糊、不同立绘、错位或未收录角色可能误匹配，请在合并前核对；也可直接在结果下拉框中更正。
测试截图 12 个位置的首选角色均正确；9 个默认勾选，3 个提示核对。缩小压缩版与 4×3 重排版也均为 12/12 首选正确；空白图无结果默认勾选。该结果仅代表这些测试图片。

角色信息
右键右侧角色卡片，可编辑等级（1～90）、共鸣链（0～6）和备注。
初始资料默认等级 90、共鸣链 0，仅作为可修改的记录，不代表你的真实练度。
搜索框支持按角色名、武器或备注搜索；可按冷凝、热熔、导电、气动、衍射、湮灭筛选。
取消角色持有时，会一并从现有队伍移除该角色，可撤销。

存档与导出
每次修改自动保存，关闭后再次打开继续使用。
Ctrl+Z：撤销上一步操作（最多 80 步，限当前运行期间）。
Ctrl+S：立即保存。
导出菜单支持配队方案 JSON、队伍图片 PNG 和复制配队文本。
JSON 包含漂泊者性别与属性设置、额外二次角色、持有角色、队伍、角色等级、共鸣链和备注，可导入恢复或迁移。
导入会先检查格式和出场规则，失败时不会修改当前方案；成功导入后仍可撤销。
存档目录：%LOCALAPPDATA%\WuwaEndstateMatrix\
plan.json 为当前存档；plan.json.bak 为上一次保存的备份。
如果原存档损坏，程序保留原文件，避免自动覆盖，并提示先导出当前编辑或导入有效方案。

v1.6 剪贴板空白预览修复
已确认部分截图工具提供的 32 位 Windows 位图，其第四个通道全部为 0。旧版将它当作透明度，导致颜色明明存在却预览全透明，随后返回 0 个角色。
现在输入图片统一转为不透明 RGB；兼容预乘透明度，并支持 PNG 和 image/png 等 MIME 格式。
标准读取缺失颜色时，会只读尝试 Windows 原始 CF_DIB / CF_DIBV5 位图，直接恢复 RGB，忽略未定义的透明度字节。
原始位图兼容 24/32 位、正向/倒序扫描行和 DIBV5 颜色掩码。读取不会修改系统剪贴板，也不会把截图保存成文件。
若剪贴板没有可见图片，会明确提示重新复制原图；没有角色结果时也会提示检查左侧预览和选区，不再仅显示已跳过空位。
升级后请先关闭旧版，重新复制游戏中的角色截图，再在工具里 Ctrl+V。左侧应立即出现角色截图预览。
验证：实际 Windows 剪贴板确认原位图透明度为 0..0，修复后读取结果为正常可见 RGB；25 项位图桥接测试通过，两个零透明度 DIB 角色图均识别 11/11。零透明度图片的窗口预览与自动识别也已检查。清空会话的 9 项检查仍通过。
新增源码：NativeClipboardImages.cs（Windows 原始剪贴板位图恢复）、ClipboardBridgeTests.cs（透明度与位图格式回归）。

v1.8 一键推荐配队
1. 先通过“管理持有”或粘贴截图设置自己拥有的角色。
2. 点击左侧“作战编队”顶部的“一键推荐”。默认仅填充完全空白的队伍，已有完整队伍和手动填写的部分队伍都会保留，并占用相应角色次数。
3. 右键“一键推荐”，可选择“重新规划全部队伍（可撤销）”或“推荐规则与攻略来源”。重新规划会替换现有队伍成员，队名、持有角色、等级、共鸣链和备注保持不变。
4. 推荐只使用已持有角色，普通角色限 1 次，白芷、维里奈、卜灵、守岸人、莫宁、穗穗限 2 次，同队禁止重复。漂泊者只采用当前选定的属性和性别。
5. 推荐器整体考虑多支队伍的角色竞争，尽量凑齐完整队伍；同等队伍数量下优先覆盖更多限定五星，再参考攻略首选、等级、共鸣链和攻略更新日期。新生成队伍按主力首次推出时间从早到晚排列。它不计算关卡抗性、当期增益、武器声骸或实际伤害，也不保证全局最优或通关分数。
6. 攻略库中没有匹配、角色未持有或剩余次数不足时，相应队伍保留空白，不会随意拼凑角色。玩家仍可手动调整。
7. 推荐后点击队伍标题旁的“攻略”，可查看作者、原站更新时间和原文链接；切换到“全部攻略”可搜索全部收录条目。手动更改成员后，与原模板不再匹配的攻略标签会隐藏。
8. 每次推荐自动保存，Ctrl+Z 可一次撤销。若计算期间玩家修改了角色或队伍，旧计算结果不会覆盖新修改。

v1.9 自动推荐新增规则
1. 优先使用已持有的限定五星：在尽量凑齐完整队伍的前提下，优先覆盖更多不同的限定五星角色，其次考虑限定五星的出场次数，再考虑攻略首选/备选、练度与更新时间。仍只从已收录攻略的组合中选择，不会为堆五星随意拼队。
2. 新推荐的队伍按主力输出角色首次推出时间从早到晚排列，主力自动放在每队第一格。辅助角色的推出时间不影响排序。
3. 主力识别参考官方攻略站的“主力输出”“快速协奏”“生存治疗”标签。优先采用独立主力输出；存在多位同等主力时取首次推出更早的一位。没有主力标签时采用攻略主角，纯治疗主角则参考队内首位非治疗角色。
4. 漂泊者、四星和五名常驻五星（维里奈、安可、卡卡罗、凌阳、鉴心）不计为限定五星。相里要等曾免费获得的限定角色以及联动限定角色仍保留限定身份。
5. “攻略”窗口会显示该队主力、首次推出日期及限定五星人数，方便核对。
6. 默认仍只填充空队，手动队伍的位置和成员保留。已经组满的旧队伍，请右键“一键推荐”→“重新规划全部队伍（可撤销）”应用新规则；Ctrl+Z 可恢复原方案。
7. 首次推出指首次可获取的日期，不使用复刻时间、攻略更新时间或角色编号代替。元数据核对日期：2026-11-09。

v2.0 漂泊者识别覆盖设置
1. 复制游戏角色截图，在主界面或识别窗口按 Ctrl+V。
2. 头像用于识别男/女性别，左上角属性图标用于识别衍射、湮灭、气动、导电。不同属性不会仅靠相同头像猜测。
3. 在核对结果中，角色下拉框显示识别到的漂泊者属性；下方性别选项可核对或修改。识别不清的项目默认不勾选，可手动选择正确属性、性别后再勾选。

5. 未识别到漂泊者或未勾选漂泊者时，不会更改原设置。多张截图结果冲突时，以截图加入顺序中最后一个已勾选的漂泊者为准。
6. 支持自动保存、JSON 导入导出和 Ctrl+Z 一次撤销。

v2.0 额外二次出场角色
1. 点击左侧底部“出场规则”旁的“特殊角色：未设置”或“特殊：角色名 ×2”。
2. 选择一名原本限用一次的角色，保存后该角色可跨队使用 2 次；同队仍不能重复放入。
3. 固定六名二次角色保持原规则，不在额外名额中，也不能叠加成 3 次。额外名额同时只能指定一名角色。
4. 可以提前设置未持有角色，但不会因此获得角色，推荐器仍只使用已持有角色。
5. 手动配队、剩余次数显示、存档校验、一键推荐和导入导出都使用同一套额外次数规则。
6. 切换或取消额外名额时，若旧角色已在两队中使用，请先手动移除一处，以免使原配队超限。
7. 漂泊者也可选为特殊角色，额外名额会随手动或截图识别引起的属性切换迁移到新形态。
