# 素材与资料来源

## 游戏角色和图标

角色头像、服饰头像、属性图标和基础角色资料来自 [Encore 鸣潮数据库](https://encore.moe/character)。相关游戏角色和图像内容属于其对应权利方，本项目不将这些第三方素材声明为原创作品。

## 配队参考

配队组合整理自 [《鸣潮》官方攻略站](https://wuwaguide.kurogames.com/zh-Hans/)的“队友推荐”栏目，内容由原站标注的玩家作者提供。作者、攻略标题和原文链接保存在 `assets/official-recommendations.json`，程序中可以逐队查看。

资料核对日期：2026-11-09。内置 168 篇中文攻略、869 个首选/备选组合。这里只保留来源和结构化搭配信息，没有打包整篇攻略正文。

## 角色推出时间与限定类型

记录在 `assets/character-recommendation-metadata.json`，其中保存了角色定位来源和首发资料参考链接。定位参考官方攻略站；首发卡池历史参考原站公告及卡池历史整理，常驻/限定类型另对照 [BannerHistory](https://bannerhistory.app/zh/wuwa-acquisition)。免费赠送不改变角色所属卡池类型，复刻时间不用于首次推出排序。

## 个人数据排除

开发过程中使用的玩家截图、截图识别中间文件、剪贴板诊断、测试账号存档、升级前存档备份和本机路径记录均未放入本次发布目录。
